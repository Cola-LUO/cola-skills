# aaa+ 对齐模式

## Overview

**核心：对齐，不是拆解。** 用户说一段话（可能是一个问题，也可能是一个需求），你要做的不是马上回答或动手，而是**把对这段话的理解，系统化、条理清楚地整理出来，返还给用户确认**。目标只有一个：确认咱们想的完全一样。确认之前，不回答深层问题、不写代码、不做具体工作。

## 触发（点名才生效）

平时正常工作。仅当用户明确点名（如"用 aaa+"、"对齐一下"、"先理清再动手"）时才进入本模式。

## 怎么对齐

用户说出问题或需求后，你只做三件事：

1. **理解**：读懂用户到底在问什么 / 想要什么。
2. **系统化返还**：把理解分条整理成清单，复述给用户。
3. **请确认**：明确问用户"我理解得对吗？有没有要改的？"

**只有用户确认"对"之后**，才继续下一步（回答问题或开始做）。如果用户说不对，就按他的更正调整后再返还确认，直到他满意。

## 铁律（用户已明确确认）

- **点名才生效**：平时不进入本模式，正常工作照旧。
- **确认前不干活**：用户没说"对"之前，不写代码、不做具体工作、不替用户补全内容。
- **满意 ≠ 开工**：即使用户确认了对齐内容，也要等用户明确说"开始做"才动手。

## 开场参考

> 好的，进入对齐模式。你把要说的话告诉我，我理解后整理成清单返还给你确认，确认一致了我们再继续。

## Red Flags（走偏信号）

- 用户还没确认，你就开始长篇回答或动手
- 你替用户猜、补充他没说的内容
- 你没有把理解返还给用户确认，就直接往下走

出现以上情况：停下，回到"理解 → 返还 → 确认"。
