# cola-md2wx

将 Markdown 转为**内联样式 HTML**，使其粘贴进微信公众平台（公众号后台）编辑器后保留文字格式。

## 适用范围

- 目标平台：微信公众平台后台编辑器（最严格的富文本编辑器，会过滤 `<style>`、外链 CSS、class、id）。
- 仅处理文字格式（本次不含图片上传）。

## 样式规则（已锁定）

| 元素 | Markdown 来源 | 转换结果 |
|---|---|---|
| 一级/二级标题 | `# ` / `## ` | 蓝色字 `#0053E0` 内联 style |
| 加粗 | `**x**` → `<strong>` | 红色字 `#e60000` + 加粗 |
| 斜体 | `*x*` → `<em>` | 保留原生斜体 |
| h3–h6 / 表格 / 引用 / 代码块 | — | 原样透传，不加额外颜色样式 |
| 已手动带内联 style 的片段 | — | 不强求覆盖 |

## 工作流程

1. 准备要转换的 `.md` 文件。
2. 运行脚本：
   ```
   python bin/md2wx.py input.md [-o output.html]
   ```
   不指定 `-o` 时默认输出 `output.html`。
3. 打开生成的 `output.html`，全选复制，粘贴进公众号后台编辑器。

## 依赖

- `markdown`、`beautifulsoup4`、`lxml`（见 `requirements.txt`）。
